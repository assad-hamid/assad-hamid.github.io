ASSAD HAMID — WEBSITE REDESIGN / GITHUB PAGES

The contents of this ZIP are ready to go at the ROOT of your
assad-hamid.github.io repository (not inside an extra subfolder).

1. Unzip the download on your computer.
2. In GitHub, open assad-hamid/assad-hamid.github.io.
3. Upload the unzipped FILES AND FOLDERS into the repository root.
4. Commit changes to the branch used by GitHub Pages (usually main).
5. In Settings > Pages, make sure the source deploys from the root
   of that branch, if you use branch-based deployment.
6. Wait for GitHub Pages to publish and hard-refresh your website.

All existing project images, CV documents, and project-page text were kept.
No npm, React, Jekyll build, or external JavaScript library is needed.
Fonts load from Google Fonts when online, with system fallbacks.
